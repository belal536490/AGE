👻 ভয় জেনারেটর

ভৌতিক লাইন জেনারেট করুন এবং Google TTS দিয়ে ভয়েস শুনুন

Google Cloud Console → APIs & Services → Credentials থেকে API Key কপি করে এখানে পেস্ট করুন।

Generated Text

এখানে ভয়ংকর টেক্সট দেখাবে...

⚙️ সমস্যা হলে কী করবেন

  • API Key error: নিশ্চিত করুন Text-to-Speech API enable করা আছে।
  • No audio: ব্রাউজারের autoplay policy এড়াতে Speak বাটন ক্লিক করার পরই প্লে করুন।
  • 403 / Permission denied: Billing account active আছে কি না চেক করুন।
  • Voice not found: `bn-BD-Standard-A` না পেলে `bn-IN-Standard-A` ব্যবহার করুন (script.js এ)।

নোট: API Key কখনো public repo-তে আপলোড করবেন না।
